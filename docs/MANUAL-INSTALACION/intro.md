# MANUAL DE INSTALACIÓN  
## APP-SPGCT  
### SISTEMA PARTICIPATIVO DE GARANTÍA COMUNITARIO Y TERRITORIAL

**VERSIÓN:** 1.1  
**ÚLTIMA ACTUALIZACIÓN:** 23 de julio de 2024  

---

## 1. INTRODUCCIÓN

El presente manual documenta de manera detallada el proceso de instalación, configuración y despliegue del sistema **APP-SPGCT**.  
La información contenida en este documento tiene carácter **informativo y referencial**, y forma parte de la documentación oficial del sistema.

Este manual no implica la ejecución directa de los procedimientos descritos, sino que tiene como finalidad explicar cómo se realiza la instalación del sistema en distintos entornos.

---

## 2. REQUISITOS DEL SISTEMA

### 2.1 REQUISITOS DE HARDWARE

Para el funcionamiento del sistema APP-SPGCT se consideran los siguientes requerimientos mínimos:

- Procesador Intel Core i5 o superior  
- Memoria RAM mínima de 8 GB  
- Espacio de almacenamiento disponible mínimo de 20 GB  
- Conexión a Internet estable  

---

### 2.2 REQUISITOS DE SOFTWARE

El sistema APP-SPGCT se encuentra diseñado para operar sobre las siguientes plataformas y herramientas:

- Sistema Operativo:
  - Windows 10 o superior
  - Ubuntu Server 20.04 o superior
- Node.js versión 18.x o superior
- Docker
- Docker Compose
- Git
- Navegador web actualizado (Google Chrome, Mozilla Firefox o Microsoft Edge)

---
