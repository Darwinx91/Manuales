## 2. REQUISITOS DEL SISTEMA

### 2.1 REQUISITOS DE HARDWARE

- Procesador: Intel Core i5 o superior
- Memoria RAM: 8 GB mínimo (16 GB recomendado)
- Almacenamiento: 20 GB libres
- Conectividad a Internet

### 2.2 REQUISITOS DE SOFTWARE

- Sistema Operativo:
  - Windows 10 / 11
  - Ubuntu Server 20.04 o superior
- Node.js versión 18.x o superior
- Docker y Docker Compose
- Git
- Navegador Web actualizado (Chrome, Edge o Firefox)

### 2.3 REQUISITOS ADICIONALES

- Acceso a repositorio GitHub del proyecto
- Permisos de administrador en el sistema operativo
