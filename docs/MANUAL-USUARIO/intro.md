# MANUAL DE USUARIO  
## APP-SPGCT  
### SISTEMA PARTICIPATIVO DE GARANTÍA COMUNITARIO Y TERRITORIAL

**Versión:** 1.1  
**Última actualización:** 23 de julio de 2024  

---

## 1. INTRODUCCIÓN

El presente **Manual de Usuario** describe el uso funcional del sistema **APP-SPGCT**, orientado a los usuarios finales que interactúan con la plataforma para la gestión participativa de información territorial y comunitaria.

Este documento tiene un enfoque descriptivo y explicativo, permitiendo comprender el funcionamiento general del sistema, sus módulos principales y las acciones que pueden realizar los diferentes tipos de usuarios.

El manual se presenta con fines académicos, formativos y de referencia, sin requerir conocimientos técnicos avanzados.

---

## 2. OBJETIVO DEL MANUAL

El objetivo de este manual es:

- Guiar a los usuarios en el uso correcto del sistema APP-SPGCT  
- Explicar las funciones disponibles en cada módulo  
- Describir los flujos principales de interacción del sistema  
- Facilitar la comprensión del sistema sin necesidad de conocimientos técnicos  

---

## 3. TIPOS DE USUARIO

El sistema APP-SPGCT contempla distintos tipos de usuarios, cada uno con funciones específicas:

### 3.1 VEEDORES

Los veedores son responsables de:

- Registrar información territorial  
- Participar en procesos de control comunitario  
- Consultar registros y reportes asignados  

### 3.2 ADMINISTRADORES

Los administradores tienen acceso completo al sistema y pueden:

- Gestionar usuarios  
- Configurar parámetros del sistema  
- Supervisar la información registrada  
- Administrar módulos y permisos  

### 3.3 PERSONAL TÉCNICO

El personal técnico se encarga de:

- Apoyo operativo al sistema  
- Verificación de información  
- Soporte funcional a los usuarios  

---

## 4. ACCESO AL SISTEMA

El acceso al sistema APP-SPGCT se realiza mediante una interfaz web o aplicación móvil.

### 4.1 INICIO DE SESIÓN

El sistema cuenta con un módulo de autenticación que permite:

- Ingresar mediante usuario y contraseña  
- Validar credenciales registradas en el sistema  
- Restringir accesos no autorizados  

### 4.2 RECUPERACIÓN DE ACCESO

En caso de problemas de acceso, el sistema permite:

- Recuperación de contraseña  
- Contacto con el administrador del sistema  

---

## 5. INTERFAZ DEL SISTEMA

La interfaz del sistema APP-SPGCT ha sido diseñada para ser intuitiva y accesible.

### 5.1 MENÚ PRINCIPAL

El menú principal permite acceder a:

- Módulos del sistema  
- Gestión de información  
- Reportes  
- Configuración de usuario  

### 5.2 PANEL DE USUARIO

Cada usuario dispone de un panel personalizado donde puede:

- Visualizar información asignada  
- Consultar registros  
- Ejecutar acciones según su rol  

---

## 6. MÓDULOS PRINCIPALES DEL SISTEMA

### 6.1 GESTIÓN DE INFORMACIÓN TERRITORIAL

Este módulo permite:

- Registrar datos comunitarios  
- Actualizar información existente  
- Consultar registros históricos  

### 6.2 VEEDURÍA Y CONTROL

El módulo de veeduría facilita:

- Seguimiento de procesos  
- Control participativo  
- Validación de información registrada  

### 6.3 REPORTES

El sistema genera reportes que permiten:

- Visualizar resultados  
- Exportar información  
- Apoyar procesos de toma de decisiones  

---

## 7. USO DE LA APLICACIÓN MÓVIL

APP-SPGCT dispone de una aplicación móvil que permite:

- Acceso remoto al sistema  
- Registro de información desde territorio  
- Consulta rápida de datos  

La aplicación móvil replica las funciones principales del sistema web, adaptadas a dispositivos móviles.

---

## 8. BUENAS PRÁCTICAS DE USO

Se recomienda a los usuarios:

- Mantener la confidencialidad de sus credenciales  
- Registrar información de forma responsable  
- Cerrar sesión al finalizar el uso del sistema  
- Reportar errores o inconsistencias al administrador  

---

## 9. VERIFICACIÓN DEL FUNCIONAMIENTO

Para un uso correcto del sistema se debe verificar:

- Acceso exitoso al sistema  
- Correcta visualización de módulos  
- Respuesta adecuada de las funcionalidades  
- Funcionamiento del inicio de sesión  

---

## 10. CONCLUSIÓN

El Manual de Usuario del sistema APP-SPGCT proporciona una guía clara y estructurada para el uso adecuado de la plataforma.

Este documento permite a los usuarios comprender las funciones disponibles, interactuar correctamente con el sistema y participar activamente en los procesos comunitarios y territoriales gestionados mediante APP-SPGCT.

El manual sirve como material de apoyo académico y de referencia para el uso cotidiano del sistema.
