## DESCRIPCIÓN GENERAL

El sistema APP-SPGCT se basa en una arquitectura de múltiples capas que permite escalabilidad, seguridad y mantenimiento eficiente.

## COMPONENTES

- Frontend Web desarrollado con Quasar Framework  
- Aplicación móvil Android  
- APIs REST desarrolladas en .NET  
- Base de datos NoSQL MongoDB  

## COMUNICACIÓN

La comunicación entre componentes se realiza mediante servicios REST, garantizando interoperabilidad y desacoplamiento.
